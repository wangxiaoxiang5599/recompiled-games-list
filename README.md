# Recompiled games list

Fan projects that turn console games into **native PC programs** instead of running them in an emulator: static recompilations (N64Recomp, XenonRecomp, ReXGlue), decompilations, game-specific runtimes and single-game emulator forks. Each project is listed with its method, its status and the PC platforms it builds for.

It is the data behind **[portedgames.com/recompiled-games](https://portedgames.com/recompiled-games/)**, where every project's status is re-checked daily. This repository syncs from it once a day.

Overview page with charts and download links: **[wangxiaoxiang5599.github.io/recompiled-games-list](https://wangxiaoxiang5599.github.io/recompiled-games-list/)**.

None of these projects include the game. Every one needs files from your own copy, and nothing here hosts or links game files, ROMs or ISOs.

Archived on Zenodo: [doi:10.5281/zenodo.23555376](https://doi.org/10.5281/zenodo.23555376) (snapshot v1.0.0; each GitHub release is archived automatically).

## Fields

| Field | Meaning |
|---|---|
| `id` | Stable identifier. |
| `game` | The original game. |
| `console` | The console the game came from (Other covers PSP and a few PC games). |
| `project` | The project's name. |
| `url` | The project's own repository or official page. Never a download of the game. |
| `method` | Static recompilation, Decompilation, Game-specific runtime or Emulator fork. |
| `stage` | Working, Beta, Early, Unconfirmed, Offline or Taken down. |
| `platforms` | PC platforms the project builds for. |
| `note` | One short factual note: what works, or a caveat. |
| `added` | When the project was added to the list (YYYY-MM-DD). |
| `lastChecked` | When its status was last checked (YYYY-MM-DD). |
| `entry` | The project's page on PortedGames, when it has one. |
| `sources` | Where the status comes from (release notes, the project's README, reporting). |

## How statuses are checked

PortedGames requests every project's repository or page once a day. A repository that returns 404 or 410 is marked Offline, one that returns 451 is marked Taken down, and the check date is updated. Working, Beta and Early come from the project's own releases and README. Takedowns have their own dataset: [fan-port-takedowns](https://github.com/wangxiaoxiang5599/fan-port-takedowns).

## Corrections

Missing a project, or a status is wrong? Open an issue with a link, or email contact@portedgames.com. Changes are made on the site and synced here, so pull requests to the data files and the list will be overwritten.
