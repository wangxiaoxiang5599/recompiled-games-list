Static recompilation translates the console's machine code into C or C++ ahead of time (N64Recomp, XenonRecomp, ReXGlue). Decompilation rebuilds readable source that compiles back into the game. PS4 projects mostly run the game's own x86-64 code with a runtime written for that one game. How each method works: how fan ports work.

Use it

// JavaScript
const rows = await (await fetch('https://raw.githubusercontent.com/wangxiaoxiang5599/recompiled-games-list/main/data/recompiled-games.json')).json();
const working = rows.filter((r) => r.stage === 'Working');
# Python
import pandas as pd
df = pd.read_csv('https://raw.githubusercontent.com/wangxiaoxiang5599/recompiled-games-list/main/data/recompiled-games.csv', parse_dates=['added', 'lastChecked'])
df.groupby(['console', 'method']).size()

Each row has the game, the console, the project and its official repository, the method, the status, the PC platforms it builds for, a short note, the dates it was added and last checked, and sources. Field descriptions are in the README.

Scope

A project is listed when it produces a program that runs a console game natively on PC and has a public repository or official page. Every project needs files from your own copy of the game: none of them ship it, and no game files, ROMs or ISOs are hosted or linked here. Missing a project or a status is wrong? Open an issue.
